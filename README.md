# HealthCopilot AI

A responsive, static wellness dashboard demo built with HTML, CSS, and JavaScript. It can be hosted on GitHub Pages.

## Files

- `index.html` — page structure and dashboard content
- `style.css` — responsive visual design
- `script.js` — mood check-in, habit tracking, water counter, and demo wellness-topic responses

## Run locally

Open `index.html` in a modern browser. No build tools are required.

## Publish with GitHub Pages

1. Upload all project files to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then click **Save**.
5. Wait for deployment to complete and open the Pages URL shown on that screen.

## Important limitations

This is a front-end demo, not a medical service. The wellness assistant uses a few built-in educational responses and is **not connected to a real AI model or healthcare database**. Do not enter sensitive personal or medical information. Check-ins and habit state are stored in local browser storage and are not synchronized between devices. The daily tracking state resets on a new date.

To add genuine AI responses, authentication, or cloud storage, connect a secure backend. Never place private API keys in browser JavaScript or public GitHub repositories.

## Medical disclaimer

HealthCopilot AI is for general wellness education only. It does not diagnose, treat, or prevent disease and is not a substitute for professional medical advice. For urgent symptoms, seek appropriate medical care.
